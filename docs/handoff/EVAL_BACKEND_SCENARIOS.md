# Backend scenarios: what was measured

56 scenarios of the backend's own (`backend/eval/scenarios.py`), run through
`/desk/eval/v1` on the real Scriba application with providers replaced by an isolated
world. Generated by `tests/integration/test_scenarios_with_scriba.py`; do not edit by hand.

Three sets, never added together: the 24 scenarios measured at `8cff1f4`; the 14 of the
reconciliation branch (dates and zones read in full or not at all, which meeting is meant,
providers that fail); and the 18 of overlay 0.4 (chat, threads, several requests, repeats,
follow-ups, finished tasks, partial failure, model outage, injection, approval replay).

**Rules only** is the Desk with no model. **Scripted model** gives the understanding step the
answer a careful reader would give, so it measures everything behind the model (validation,
planning, checks, approvals, execution, verification) and is an upper bound for this
pipeline, not a model's score. A real model is measured separately, from outside the test
suite: see `EVAL_CONFIGURED_MODEL.md`.

Latency is the pipeline's own time in a sandbox with no model call.
